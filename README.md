# 💎 Brumeval

Une aventure en vue de dessus, en HTML, CSS et JavaScript, sans aucune dépendance.

Tu incarnes un jeune héros arrivé dans un village médiéval endormi par la Brume :

- Récolte du bois, de la pierre, du fer, des cristaux, des baies, des champignons et des poissons
- Aide les villageois à travers 11 quêtes : répare le pont, ouvre la grotte, rallume le Cristal…
- … puis affronte **Ignar, le Dragon des Cendres**, dans un combat de boss
- Cycle jour/nuit, lumières, brume, musique et sons générés par le navigateur
- Boutiques, améliorations d'outils, commandes de Gus
- Sauvegarde automatique, jouable sur ordinateur et sur mobile

## Commandes

- **ZQSD / WASD / flèches** : se déplacer
- **E / Espace** : interagir (maintenir pour récolter)
- **F / clic** : coup d'épée · **H** : boire un élixir
- **J** journal · **I** sac · **M** carte

Pour jouer en local : ouvre `index.html` dans un navigateur.
